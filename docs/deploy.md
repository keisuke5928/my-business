# 本番に公開する手順

2026年11月15日。宿のはじめて帳を、Firebase（東京）に公開する手順です。
1回目は1時間ほどかかります。2回目からは、手順5の命令を1回動かすだけです。

## 1. 吉田さんが用意するもの

### 手順1 Firebase のプロジェクトを作る
1. https://console.firebase.google.com/ を開き、Googleのアカウントでログインする。
2. 「プロジェクトを作成」。名前は例えば `yado-hajimete`。Googleアナリティクスはオフでよい。
3. できたプロジェクトの「プロジェクトID」を控える（名前の下に小さく出る。例 `yado-hajimete-1a2b3`）。
4. 左下の「アップグレード」から、料金プランを「Blaze（従量課金）」にする。サーバー側の処理（AIの呼び出しなど）に必要です。
5. 同じ画面で「予算アラート」を設定する。例えば月3,000円。使いすぎたときにメールが届きます。
   1. 試行の規模（1館、新人数人）なら、Firebase の費用は無料の範囲に収まる見込みです。

### 手順2 データベースとログインを有効にする
1. 左のメニュー「Firestore Database」→「データベースを作成」。
   1. 場所は **asia-northeast1（東京）** を選ぶ。**あとから変えられません。**
   2. 「本番環境モード」で作る（読み書きの決まりは、手順5で入ります）。
2. 左のメニュー「Authentication」→「始める」→「Sign-in method」で、次の2つを有効にする。
   1. 「メール/パスワード」を開き、「メールリンク（パスワードなしでログイン）」をオンにする。
   2. 「匿名」をオンにする。

### 手順3 AnthropicのAPIキーを作る
1. https://console.anthropic.com/ でアカウントを作り、支払い方法を登録する。
2. 「API Keys」でキーを作り、どこかに控える。**チャットには貼らないでください。** 手順5で、画面に出ない形で入れます。
3. 「Limits」で、月の使用額の上限を決めておくと安心です。目安は1館あたり月1,000円ほどです（docs/hosting-plan.md）。

### 手順4 ウェブアプリの設定を写す
1. Firebase のプロジェクトの「プロジェクトの設定」（歯車）→「マイアプリ」→「</>」（ウェブ）でアプリを足す。名前は何でもよい。Hosting のチェックは入れなくてよい。
2. 出てきた `firebaseConfig` の中の `apiKey`、`authDomain`、`projectId`、`appId` の4つを控える。
   1. この4つは、公開されても問題ない種類の値です（APIキーという名前ですが、秘密の鍵ではありません）。チャットに貼っても大丈夫です。

## 2. 公開する

### 手順5 公開の命令を動かす
パソコンを使わずに、ブラウザの中で動かせる **Google Cloud Shell** をおすすめします。必要な道具（Node.js、Python、git）が最初から入っています。

1. https://shell.cloud.google.com/ を開く（手順1と同じGoogleのアカウント）。
2. このリポジトリを Cloud Shell に入れる。どちらかの方法で。
   1. Claude から受け取った zip を、Cloud Shell の画面右上の「︙」→「アップロード」で入れ、`unzip my-business.zip -d my-business` で開く。
   2. または `git clone https://github.com/keisuke5928/my-business`（非公開のリポジトリなので、GitHub のログインを求められます）。
3. 設定ファイルを作る。

```bash
cd my-business
cp firebase/config.example.json firebase/config.json
```

4. `firebase/config.json` を開いて（Cloud Shell の「エディタを開く」）、手順4の4つの値を入れる。`"_説明"` の行は消してもそのままでもよい。
5. 公開の命令を動かす。`yado-hajimete-1a2b3` は手順1のプロジェクトIDに変える。

```bash
bash scripts/deploy.sh yado-hajimete-1a2b3
```

6. 途中で聞かれること。
   1. はじめての時は、Firebase へのログイン。表示されるURLを開き、Googleでログインし、出てきた文字を貼りつける。
   2. 運営者のメールアドレス。
   3. AnthropicのAPIキー（手順3）。貼りつけても画面には出ません。
   4. Google Cloud の機能を有効にしてよいか、と聞かれたら「Y」。
7. 最後に「公開しました。」と、ホームページとログインのURLが出たら終わりです。

## 3. 公開したあとにすること

1. 運営者のログインのURL（`https://<プロジェクトID>.web.app/entaiji/#login`）を開き、運営者のメールアドレスを入れる。届いたメールのリンクを、**同じ端末のブラウザで**開く。
2. 「メモ」画面で、旅館の管理者のメールアドレスを登録する。
3. 管理者がログインし、「新人」画面で受け入れる人を足し、人ごとの画面で「本人あてのリンク」を作って本人に送る。
4. 試しに、自分のスマホで本人あてのリンクを開き、「中抜けは何時から？」「卵アレルギーの料理は？」と聞いてみる。

## 4. 2回目から（中身を直したとき）

```bash
cd my-business
git pull
bash scripts/deploy.sh yado-hajimete-1a2b3
```

ログイン、メールアドレス、APIキーは、もう聞かれません。

## 5. 困ったとき

1. 「Blaze にしてください」と出る。手順1の4がまだです。
2. 「Firestore のデータベースがありません」と出る。手順2の1がまだです。
3. ログインのメールが届かない。迷惑メールのフォルダを見てください。Authentication の「メールリンク」がオンかも確かめてください。
4. 質問係が「混み合っています」としか答えない。AnthropicのAPIキーか、支払いの登録を確かめてください。1日の上限（宿ごとに300回）に達したときも、この表示になります。
5. それでも分からないときは、出た文をそのまま Claude に貼ってください。APIキーだけは貼らないでください。
