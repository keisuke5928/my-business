## 1. 確認してほしいこと

### 専門家に確認すること
1. 役割の分け方。スタッフの情報は、施設が使う目的で吉田が預かる（委託）形にするか、吉田が自分の事業として集める形にするか。下書きは「施設のための情報は委託、外部の相談窓口は吉田自身」にしています。
2. 外国の会社への提供。AIは Anthropic社（アメリカ）、保存は Google社（Firebase。保存場所は東京）を使います。個人情報保護法28条の説明と同意が、この書き方で足りるか。
3. 体調やけがの情報。「困ったら」ボタンや相談に、健康のことが書かれることがあります。要配慮個人情報として、入るときの同意で足りるか。
4. 18歳未満のスタッフ。おてつたびなどで学生が来る場合、保護者の同意がいるか。
5. 派遣スタッフ。雇い主は派遣会社で、働く場所は施設です。施設が派遣スタッフの情報をこのアプリに入れてよいか、派遣会社との取り決めが必要か。
6. 責任の範囲。無償の試行で、責任をどこまで負うか（第10条）。
7. 裁判所。どこにするか（第14条）。

### 施設と決めること
1. 試行の期間と、終わったあとのデータの扱い（消す、または引き継ぐ）。
2. 施設の管理者として登録する人（メールアドレス）。
3. 外部の相談窓口に届いた声を、施設にどう伝えるか。安全に関わることは、本人が外部を選んでも、名前を伏せたうえで当日中に施設へ伝える運用にしています。施設の連絡先（誰に、どの方法で）。
4. 施設と吉田の間の「試行の覚書」（個人情報の委託の取り決めを含む）。この下書きとは別に作ります。

### 吉田が調べて書き入れること
1. Anthropic社が、送った文をどれだけの期間保存するか（そのときの規約で確認）。
2. 事業者名、住所、問い合わせ先のメールアドレス。

## 2. 利用規約

### 第1条 この規約について
1. この規約は、【事業者名：吉田圭佑】（以下「運営者」）が提供する「宿のはじめて帳」（以下「アプリ」）を使うときの決まりです。
2. アプリを使う人は、この規約に同意したものとします。
3. 使う人は次の2つです。
   1. スタッフ。施設で働く新人の方。招待リンクから入ります。
   2. 管理者。施設で受け入れや教育を担当する方。運営者が登録します。

### 第2条 アプリでできること
1. 新人の方が、仕事の流れ、館内の案内、教材、テストを見られます。
2. 分からないことを、AIの質問係に聞けます。AIが答えられないときは、施設の担当者に質問が届きます。
3. ふりかえりや相談を、施設または外部の相談窓口（運営者）に送れます。
4. 管理者は、受け入れの準備、一人立ちまでの確認、連絡、質問への回答ができます。

### 第3条 試行について
1. 【2026年11月◯日から◯月◯日まで】は試行の期間です。料金はかかりません。
2. 試行の期間中は、運営者が予告なく内容を直すことがあります。

### 第4条 入り方とログイン
1. スタッフは、施設から受け取った招待リンクで入ります。名前やメールアドレスの登録はいりません。
2. 管理者は、登録したメールアドレスに届くリンクでログインします。
3. 招待リンクとログインのリンクは、ほかの人に渡さないでください。
4. 招待リンクが外に漏れたときは、管理者が新しいリンクに作り直せます。古いリンクでは入れなくなります。

### 第5条 AIの答えについて
1. AIの答えは、施設の資料をもとにした参考です。間違えることがあります。
2. 施設の担当者や先輩の指示が、AIの答えより優先です。
3. AIは、次のことには答えません。施設の担当者に回します。
   1. アレルギー
   2. けが、体調
   3. お金（給料、手当など）
   4. お客様とのトラブル
   5. ハラスメント
   6. 災害
4. 命に関わるときは、アプリを使わずに、すぐ近くの人に知らせて、119番に電話してください。

### 第6条 してはいけないこと
1. お客様の名前、部屋番号と結びついた個人のこと、連絡先などを書き込むこと。
2. ほかのスタッフの悪口や、個人を傷つける書き込み。
3. 招待リンクやログインのリンクを、施設の外の人に渡すこと。
4. アプリの仕組みを壊す、またはわざと大量に使うこと。
5. 法律や施設の決まりに反すること。

### 第7条 書き込んだ内容
1. 質問、ふりかえり、相談などの内容は、第3章「個人情報の扱い」に書いたとおりに扱います。
2. 施設の担当者が書いた回答や教材は、施設のものです。運営者は、施設のアプリを動かし、直すためにだけ使います。

### 第8条 アプリの変更と停止
1. 運営者は、アプリの内容を変えることがあります。
2. 次のときは、アプリを止めることがあります。
   1. 点検や修理をするとき。
   2. 使っているサービス（Google社、Anthropic社）が止まったとき。
   3. 災害など、やむを得ないとき。
3. AIが使えないときも、資料をそのまま探す機能は使えるようにしています。

### 第9条 利用の停止
1. 第6条に反したときは、その人の利用を止めることがあります。
2. 施設をやめたスタッフは、管理者が招待リンクを作り直すことで、新しく入れなくなります。

### 第10条 責任について
1. 運営者は、アプリが正しく動くよう努めます。
2. AIの答えや資料の内容で起きたことは、運営者に故意または重大な過失があるときを除き、責任を負いません。【範囲は専門家と確認】
3. 仕事の判断は、施設の指示に従ってください。

### 第11条 利用の終わりとデータ
1. 施設との試行または契約が終わったら、施設のデータは【3か月以内】に消します。施設が求めた場合は、消す前に書き出して渡します。
2. 消す前でも、施設やスタッフ本人から求めがあれば、第3章のとおり対応します。

### 第12条 規約の変更
1. 運営者は、この規約を変えることがあります。
2. 変えるときは、アプリまたは施設を通して、事前に知らせます。

## 3. 個人情報の扱い（プライバシーポリシー）

【事業者名：吉田圭佑】（以下「運営者」）は、「宿のはじめて帳」で預かる個人情報を、次のとおり大切に扱います。

### 1. 集める情報
1. スタッフの情報
   1. 名前（初日シートに施設が書いた名前、または本人が入れた名前）、職種、働き始めの日
   2. 質問の文と、送った日時
   3. ふりかえりの答え（5段階）と、書いた内容
   4. 外部の相談窓口に送った内容
   5. 「困ったら」ボタンで知らせた内容。体調やけがのことが入ることがあります
   6. 一人立ちまでの確認（できたこと、教えた人、日付）、引き継ぎのメモ
2. 管理者の情報
   1. メールアドレス
   2. 書いた回答、連絡、教材、メモ
3. 自動で記録される情報
   1. ログインのための番号（端末ごとに自動で作られる番号）
   2. AIを使った回数
4. 端末の中にだけ残す情報
   1. 開いた画面、文字の大きさ、教材の訳など。運営者には送られません。

### 2. 使う目的
1. 新人の方が、仕事を覚え、困ったときに助けを得られるようにするため。
2. 施設の担当者が、質問に答え、受け入れと教育を進めるため。
3. 外部の相談窓口として、スタッフの声を受け取り、本人の希望に沿って施設に伝えるため。
4. 教育にかかる時間や、一人立ちまでの日数を、名前を出さない数字にまとめて、施設に報告するため。
5. アプリを直し、よくするため。
6. 問い合わせに答えるため。

### 3. 誰が見られるか
1. 施設の管理者は、その施設のスタッフの質問、ふりかえり、確認の記録を見られます。
2. ほかの施設の人は、見られません。施設ごとにデータを分けています。
3. 外部の相談窓口に送った内容は、運営者だけが見られます。施設の管理者は見られません。
4. 外部の相談窓口に送った内容を施設に伝えるときは、本人の希望に沿い、名前を伏せます。
5. ただし、命、けが、体調、ハラスメントなど、安全に関わる内容は、本人が外部を選んだ場合でも、名前を伏せたうえで、当日中に施設に伝えることがあります。

### 4. 外の会社に預けること
アプリを動かすために、次の会社のサービスを使います。運営者は、預け先が情報を正しく扱うよう、契約と設定で管理します。
1. Google LLC（アメリカ）。Firebase。データの保存とログイン。保存場所は日本（東京）です。
2. Anthropic, PBC（アメリカ）。AI（Claude）。質問の文と、施設の資料をAIに送り、答えを受け取ります。
   1. Anthropic社の規約では、送った内容をAIの学習には使いません。
   2. 安全の確認のため、【◯日間】保存されることがあります。【Anthropic社の規約で確認】
3. アメリカには、日本の個人情報保護法と同じような、国全体の個人情報の法律はありません。州ごとの法律があります（例 カリフォルニア州）。個人情報保護委員会が国ごとの制度をまとめた資料を公開しています。
4. 2つの会社は、それぞれ個人情報を守るための体制（国際的な基準の認証など）をとっています。【各社の公開資料で確認して書き入れる】

### 5. ほかの人に渡すこと
1. 次のときを除き、本人の同意なしに、ほかの人に渡しません。
   1. 法律で求められたとき。
   2. 命、体、財産を守るために必要で、本人の同意を得るのが難しいとき。
2. 施設に名前を出さない数字で報告することは、ここでいう「渡す」にあたりません。

### 6. 守るための取り組み
1. 決まりを作る。この文書と、運営者の取り扱いの手順を定めています。
2. 人の管理。データを扱うのは運営者1人です。
3. 仕組みの管理。
   1. 施設ごと、役割ごとに、読める範囲を分けています。
   2. 通信はすべて暗号化しています。
   3. AIの鍵などの大事な情報は、サーバーにだけ置いています。
   4. 招待リンクは作り直せます。
4. 外国にあるサービスを使うので、その国の制度を確かめたうえで管理しています（4を参照）。

### 7. 残す期間
1. 施設との試行または契約の間、残します。
2. 終わったあと【3か月以内】に消します。
3. 外部の相談窓口に送った内容は、対応が終わってから【1年】で消します。

### 8. 見る、直す、消す、止める
1. 本人は、自分の情報を見る、直す、消す、使うのを止めることを求められます。
2. 下の問い合わせ先に連絡してください。本人であることを確かめてから、対応します。
3. スタッフは名前を登録しないため、本人の確認に、施設の管理者の協力をお願いすることがあります。ただし、外部の相談窓口に送った内容について求めるときは、施設を通さずに対応します。
4. 費用はかかりません。

## 4. スタッフ向けの短い説明（入るときに出す文）

アプリに入る前に、読んでください。

1. 質問、ふりかえり、確認の記録は、この施設の担当者が見ます。ほかの施設の人は見られません。
2. 「外部の相談窓口」を選んで送った内容は、運営者（吉田）だけが見ます。施設には、あなたの希望に沿って、名前を伏せて伝えます。
3. ただし、命、けが、体調、ハラスメントなど、安全に関わることは、名前を伏せて、その日のうちに施設に伝えることがあります。
4. AIの答えには、アメリカの会社（Anthropic社）のAIを使います。質問の文がその会社に送られます。AIの学習には使われません。
5. AIの答えは参考です。担当者や先輩の指示を優先してください。アレルギー、けが、体調、お金のことは、AIは答えず、担当者に回します。
6. お客様の名前など、お客様のことは書き込まないでください。
7. 自分の情報を消したいときは、【問い合わせ先】に連絡してください。
