# 宿のはじめて帳 リサーチ用の資料

2026年11月15日。claude.ai のチャットの「リサーチ」に添付して使う資料です。
スタッフの個人情報、旅館から聞いた内部のこと、人材会社の社内情報は入れていません。

---

## 1. サービスの概要

1. 名前は「宿のはじめて帳」。
2. 定義は「現場に入って、その宿の新人教育を作り、使われ続けるところまで面倒を見るサービス」。
3. 形はセミオーダー型。アプリの仕組みと基本の教材は全館共通で、宿ごとの中身だけを差し替える。
4. 対象は北陸（富山、石川、福井）の中小旅館（客室20〜80室）。派遣、パート、短期スタッフの入れ替わりが多い宿。
5. 運営者は個人事業主1人。前職は宿泊業向け人材派遣の営業。15〜20館を1人で保守できる作りにする。
6. 1館目の候補は富山県の宇奈月温泉の旅館（客室73室）。まだ提案前。12月中旬以降に1部署の現場診断をお願いする予定。11月中に、実際のスタッフで試す予定。

## 2. 約束する成果

1. 新人に教える時間を減らす。
2. 一人立ちまでの日数を短くする。
3. 早く辞める人（2週間以内）を減らす。

## 3. 提供の流れと料金の仮説

1. 現場診断（2〜3日）。現場に入り、仕事の流れと今の教え方を見る。
2. 構築（2〜4週間）。その宿の初日シート、教材、質問係の資料を作る。
3. 運用（月額）。月1回、届いた質問や声をもとに中身を直す。

料金の仮説（まだ決めていない。ホームページには載せていない）
1. 現場診断のみ 5万円
2. 1部署プラン 構築15万円、月額1.5万円
3. 全館プラン 構築40万円、月額3万円
4. 1館目は無償の試行

1館あたりの運営者の作業は、構築40時間以内、更新は月3〜5時間以内をめざす。

## 4. アプリでできること（いま動いているもの）

アプリはスマホのブラウザで開く。ダウンロードはいらない。新人は招待リンクを開くだけで入れる（名前の登録なし）。

### 新人スタッフの画面（5つ）
1. 初日：集合の時間と場所、迎える人、当日の流れ、持ち物、館内マップ、スタッフの決まり、寮までの道、宿の言葉。いちばん上に「次にやること」を1つ出す。言葉や部屋番号をその場で探せる。
2. 教材：仕事ごとの3分の教材（手順、やってはいけないこと、この宿だけのこと）。英語、ベトナム語、インドネシア語、ネパール語、中国語、ミャンマー語にAIで訳せる。
3. 質問：AIの質問係が、宿の資料だけから答える。資料にないことは作らず、担当者に回す。担当者の回答は資料に貯まり、次からは質問係が答える。とっさの一言（日本語と英語）。
4. テスト：教材ごとの確認テストと、覚えるカード（お品書き、館内、用語）。
5. ふりかえり：5段階の答え（体の調子、仕事の量、質問のしやすさ、生活、続けられそうか）と自由記述。書いた内容は、施設の教育担当か、外部の相談窓口（運営者）かを本人が選べる。名前を伏せることもできる。
6. 「困ったら」ボタン：体調、けが、お客様とのトラブルは、すぐ人へつなぐ。

### 旅館の管理者の画面
1. 新人：今日のまとめ、受け入れ予定の一覧（準備の進み、一人立ちチェック、引き継ぎメモ、ふりかえり）、仕事ごとの一人立ち、今週のまとめ（報告用の文）、人手の見通しと人材の依頼文。
2. 質問：新人から届いた質問に答える。AIが回答案を作る。
3. 初日シート：新人ごとの初日シートを作って送る。
4. 教材づくり：ベテランの説明（文字起こし）から、AIで教材とテストの下書きを作る。学習の記録から「つまずきやすい所」（まちがいの多い問題、覚えにくいカード）を出す。
5. 効果：新人の人数、教える時間、同じ説明の時間、時給から、1年に毎回同じ説明に使っている時間と金額を出す。

### 運営者の画面
1. 訪問時のヒアリングメモ。
2. 外部の相談窓口に届いた声。名前を伏せて施設に伝える。
3. 届いた人材の依頼。
4. 管理者の追加、招待リンクの作り直し。

### AIが答えないこと（変えない決まり）
アレルギー、けが、体調、お金（給料、手当）、お客様とのトラブル、ハラスメント、災害。これらは答えを作らず、必ず担当者に回す。

### 集めるデータ
1. 質問と回答（質問係が答えた数、担当者に回った数）。
2. 学習の記録（教材を見終わった、テストの正誤、カードの結果）。名前をつけずに集め、教材を直すためと成果を見せるためだけに使う。
3. ふりかえりの答え。
4. 一人立ちチェック（教えた人と日付）。

## 5. 技術と守ること

1. 本番は Firebase（東京リージョン）。宿ごとにデータを分け、ほかの宿から見えない。
2. AIは Anthropic の Claude（API）。宿ごとに1日のAIの回数に上限がある。AIが使えないときも、資料をそのまま探す機能は動く。
3. 利用規約と個人情報の扱いは下書きがある（専門家の確認前）。
4. 宿泊客の口コミは画面に出さない。旅館の今の教え方を否定する言い方はしない。

## 6. ほかにあるもの

1. ホームページ（料金は載せず、相談フォームで受ける）。
2. 新人教育かんたん診断（12問、4分野、24点満点）。旅館の人が自分で答えるか、訪問のときに一緒に答える。結果に「最初に手をつけるとよいところ」が出る。

## 7. まだ決まっていないこと、分からないこと

1. 料金が旅館にとって高いか安いか。
2. 旅館とは別に、派遣会社がお金を出す形がありうるか（着任前の教育として）。
3. 旅館がこのサービスに使える補助金。
4. 似たサービスとの違いを、どう言えば伝わるか。
5. 新人スタッフが本当にスマホで見るか。仕事中にスマホを見てよい旅館がどれくらいあるか。
6. 2館目以降をどう見つけるか。

## リサーチで調べてほしいこと

添付した資料のサービスについて、次を調べて、日本語でまとめてください。出典をつけてください。

1. 似たサービスの比較。宿泊業や飲食業向けの教育アプリ、動画マニュアル、マニュアル作成ツール、AIの社内質問対応。名前、料金、できること、弱いところを表にする。このサービスと重なる所と、重ならない所。
2. 市場。北陸3県の旅館の数（客室20〜80室の規模が分かれば）。宿泊業の人手不足、派遣、スキマバイト、外国人スタッフの使い方の動き。
3. 補助金と助成金。旅館がこのサービスの費用に使えそうな国、県、市町村の制度。名前、対象、補助の割合、締め切り、このサービスが当てはまりそうか。
4. 料金。資料の料金の仮説は、似たサービスや旅館の予算と比べてどうか。
5. このサービスが勝てそうな点、負けそうな点、最初の5館を取るためにやるとよいこと。
